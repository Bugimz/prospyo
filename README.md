# Spy Game (ProSpy)

اپلیکیشن با Flutter و GetX توسعه داده شده و یک نسخه دیجیتال از بازی «جاسوس» را به‌صورت کاملاً آفلاین و مبتنی بر پایگاه داده محلی ارائه می‌کند.

## ویژگی‌های فعلی
- **ناوبری و وضعیت با GetX:** مسیرهای تعریف‌شده، بایندینگ کنترلرها و مدیریت واکنش‌گرا برای صفحه‌های اصلی بازی.
- **پایگاه داده محلی نسخه‌دار:** مهاجرت نسخه 3 با ستون‌های برچسب و سختی، شمارش کلمات هر دسته و حذف خودکار داده‌های قدیمی (مثل دستهٔ حیوانات) در اولین اجرا.
- **کتابخانه کلمات بهینه‌شده:** مکان‌ها، وسایل خانه، سفر، خوراکی و شغل با برچسب موقعیت و درجه سختی برای طرح سؤال دقیق‌تر و بدون دستهٔ حیوانات.
- **مدیریت کامل کلمات دلخواه:** در صفحهٔ لیست دسته‌بندی می‌توان کلمات جدید افزود، ویرایش یا حذف کرد و با برچسب/سختی فیلتر نمود.
- **هستهٔ فانکشنال برای کلمات:** انتخاب کلمات تصادفی و فیلتر تگ‌ها با سرویس `WordLogic` انجام می‌شود تا وضعیت‌ها بدون دستکاری آبجکت‌ها و با کلید یکتا مدیریت شود.
- **مدیریت نقش‌ها و کارت‌ها:** تعیین تعداد جاسوس و شهروند، نقش‌های ویژه (گشتاپو، سلاخ، شهروند خائن) و جلوگیری از تکرار ایندکس نقش‌ها بین راندها.
- **افزونه‌ها کاملاً آفلاین:** رول‌های اضافی بدون نیاز به پرداخت یا اتصال اینترنت فعال و خاموش می‌شوند و وضعیت‌شان در حافظه محلی ذخیره می‌شود.
- **پشتیبانی حساب طلایی:** گزینه خرید/بازیابی از طریق Flutter Poolakey در کنار فعال‌سازی آفلاین برای کاربرانی که نسخه طلایی را قبلاً خریداری کرده‌اند.
- **راهنمای پرسش داخل بازی:** برای هر دسته ۳ پیشنهاد سؤال آفلاین نمایش داده می‌شود و از سوییچ «نمایش پیشنهاد سؤال» می‌توان آن را خاموش/روشن کرد.
- **تنظیمات زمان بازی:** حالت محدود یا نامحدود، انتخاب دقیقه/ثانیه و شمارش معکوس؛ پایان تایمر به‌صورت خودکار در آمار ثبت می‌شود.
- **داشبورد آمار آفلاین:** شمارش راند، میانگین زمان و پراکندگی دسته‌ها در صفحهٔ «آمار بازی» با امکان پاک‌سازی کامل داده‌ها.
- **صفحات راهنما و آموزش:** توضیح قوانین، نقش‌ها و جریان بازی برای آشنایی سریع بازیکنان.
- **رابط کاربری راست‌به‌چپ:** متن‌ها و فونت‌های فارسی با رنگ‌بندی منسجم برای هماهنگی با کاربران فارسی‌زبان.

## ایده‌های گسترش امکانات
- **پروفایل و تاریخچه راندها:** ثبت نتیجه هر راند، تعداد برد/باخت تیم‌ها و میانگین زمان حدس.
- **راهنمای تعاملی داخل بازی:** نمایش نکته‌ها یا پیشنهاد سؤال در هر راند بر اساس نقش فعال هر بازیکن.
- **پشتیبانی صدا و ویبره:** اعلام شروع/اتمام زمان یا تغییر نقش‌ها با افکت‌های کوتاه برای جذابیت بیشتر.
- **تم‌های رنگی قابل انتخاب:** سوئیچ بین حالت روشن/تاریک یا رنگ‌بندی‌های متفاوت برای جمع‌های مختلف.
- **پکیج‌های کلمهٔ شخصی:** ذخیره و بازآوری چند فهرست دلخواه برای موقعیت‌های مختلف (مهمانی، اردو، کلاس درس).
- **چالش و مأموریت روزانه:** ارائه دستاوردها و چالش‌های کوتاه برای تشویق بازی‌های مکرر (مثلاً «سه راند بدون جاسوس شکست‌خورده»).
- **پخش و به‌اشتراک‌گذاری کلید بازی:** تولید کد جلسه برای هم‌زمان‌سازی دسته‌بندی و رول‌ها میان گوشی‌های مختلف به‌صورت آفلاین با QR یا NFC.
- **پروفایل و شخصی‌سازی رول‌ها:** امکان تغییر نام/آیکن رول‌ها یا اضافه کردن رول سفارشی با توضیح و قدرت‌های ساده.
- **پک مهمانی سریع:** الگوهای آماده (Party, Classroom, Trip) که زمان، تعداد جاسوس و دسته‌بندی‌های پیشنهادی را از پیش ست می‌کند.

## نقشه راه پیشنهادی
1. **پاک‌سازی داده‌های قدیمی:** حذف کامل دستهٔ جانوران و یکسان‌سازی پایگاه دادهٔ کاربران با لیست جدید.
2. **تکمیل مدیریت محتوا:** امکان ویرایش و حذف کلمات سفارشی در کنار افزودن، و تگ‌گذاری سطح سختی یا موقعیت استفاده.
3. **راهنمای پرسش:** ساخت لیست پیشنهاد سؤال برای هر دسته تا بازیکنان راحت‌تر گپ بزنند.
4. **آنالیتیکس درون‌برنامه‌ای:** رصد استفاده از دسته‌بندی‌ها و زمان راندها برای بهبود UX.
5. **تست و اتوماسیون:** افزودن تست‌های ویجت/واحد برای کنترلرها، و لوله CI برای بررسی فرمت کد و کیفیت.

## مراحل اجرایی پیشنهادی (با تایید شما به‌صورت گام‌به‌گام)

### مرحله 1: پاک‌سازی و همسان‌سازی محتوا
**وضعیت:** ✅ انجام شد
- حذف کامل دستهٔ حیوانات از پایگاه داده فعلی و اسکریپت بذر کلمات.
- اضافه کردن مهاجرت/نسخهٔ بذر برای اطمینان از همسان‌سازی دیتابیس کاربران با لیست جدید در اولین اجرای بعد از به‌روزرسانی.
- تست دستی: اجرای برنامه تازه نصب‌شده و همچنین آپدیت روی دیتابیس قبلی برای اطمینان از حذف دسته‌ها.

### مرحله 2: مدیریت پیشرفتهٔ کلمات
**وضعیت:** ✅ انجام شد
- افزودن UI و کنترلر برای ویرایش و حذف کلمات سفارشی (در کنار افزودن موجود).
- پشتیبانی از برچسب سختی یا موقعیت (مثلاً «مهمانی»، «کلاس درس») برای هر کلمه و ذخیره در پایگاه داده.
- به‌روزرسانی فیلتر/لیست دسته‌ها بر اساس برچسب‌ها و نمایش در صفحه انتخاب دسته‌بندی.
- تست دستی: ایجاد، ویرایش، حذف و فیلتر کردن کلمات با برچسب‌های متفاوت.

### مرحله 3: راهنمای پرسش و الهام‌بخش
**وضعیت:** ✅ انجام شد
- تعریف ساختار داده برای «پیشنهاد سؤال» مرتبط با هر دسته (حداقل 3–5 پیشنهاد برای شروع).
- نمایش نکته‌ها داخل صفحه بازی یا کارت نقش، با قابلیت خاموش/روشن کردن از تنظیمات.
- بسته‌بندی محتوا به‌صورت آفلاین (JSON/بذر دیتابیس) تا نیاز به اینترنت نباشد.
- تست دستی: مشاهده پیشنهادها در چند دسته و اطمینان از عدم مزاحمت UI.

### مرحله 4: آمار و تحلیل درون‌برنامه‌ای
**وضعیت:** ✅ انجام شد
- ثبت رویدادهای کلیدی (انتخاب دسته، طول راند، برنده/بازنده) در یک لایهٔ محلی.
- ارائه داشبورد ساده داخل برنامه (مثلاً صفحهٔ پروفایل) برای نمایش شمارش راندها، میانگین زمان، پراکندگی دسته‌ها.
- گزینهٔ «پاک کردن داده‌های آماری» برای احترام به حریم خصوصی.
- تست دستی: اجرای چند راند و بررسی به‌روزرسانی داشبورد.

### مرحله 5: تست و اتوماسیون
- نوشتن تست واحد برای کنترلرهای بازی، کلمات و نقش‌ها با تمرکز بر سناریوهای اصلی (تخصیص نقش، بازنشانی کلمات، برچسب‌ها).
- افزودن تست ویجت برای صفحه‌های کلیدی (صفحه انتخاب دسته، شروع بازی) با پوشش تعاملات اصلی.
- راه‌اندازی خط CI (GitHub Actions) برای اجرای `flutter analyze`, `flutter test` و چک فرمت.
- تست: اجرای لوکال تست‌ها و مشاهده عبور pipeline در PR.

## اجرای پروژه
1. وابستگی‌ها:
   ```bash
   flutter pub get
   ```
2. اجرای اپلیکیشن:
   ```bash
   flutter run
   ```
3. ساخت نسخه تولید:
   ```bash
   flutter build apk --release
   ```
